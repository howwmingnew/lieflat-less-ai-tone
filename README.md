**一個基於 283 萬字語料統計的去 AI 味 skill**

這個 skill 希望用語言學的研究方式，來量化「什麼是 AI 味」，並致力於去除 AI 寫作的「AI 味」。該 skill 在 [moxt.ai](https://moxt.ai) 製作。

研究以 629 篇文章（2,826,972 漢字，95,551 句，45,721 段）建立對照語料，其中 300 篇由五個主流模型在受控條件下生成，329 篇為人類作者的寫作文本。檢驗了 26 項在公共討論中被廣泛認作「AI 文風」的候選特徵，逐項計算生成側與人類側的頻率比。

結果顯示，11 項特徵通過檢驗，有明顯的區分度，其中區分力最強者為段首零回指評論（4.4 倍）。另有 15 項不具備區分力，部分項的方向與流行認知相反：人類使用比喻的頻率為生成文本的 2.4 倍，正文設問句為 17 倍，句內同構排比亦高於生成文本。

研究同時發現，不同大模型的「AI 味」表現不同。例如破折號，DeepSeek 每千字 5.16 次、Claude 4.25 次，而 GPT 只有 0.11 次，全距達四十倍；提示性冒號最重的是 DeepSeek 與 Claude，問句小標題最重的是 Gemini。所謂「AI 文風」並非單一形態。

文末報告了六次因量測規則設計缺陷導致的測量失誤及其修正過程，並討論了單一模型樣本、分母選擇與語料不可核驗三項方法侷限。

**關鍵詞** 生成文本識別；中文句法；語料庫語言學；篇章銜接；對照研究

## 1 問題

大語言模型生成的中文文本存在某種可感知的風格特徵，公共討論中稱之為「AI 味」。這一判斷在寫作者社群中具有高度共識，但支撐它的證據基本停留在個案觀察層面。

流通中的判別清單大致包含以下條目：破折號使用過密；對舉結構（「不是 A 而是 B」）反覆出現；句長分布過於均勻；單字虛詞（就、很、了）偏少；以具體物象包裝抽象概念（「記憶的倉庫」）；設問後立即自答。這些條目通過社交媒體反覆傳播，逐步取得了近似常識的地位。

問題在於，它們從未被系統檢驗。清單中的條目來源各異，有的出自對早期模型輸出的觀察，有的來自英文語境的研究結論直接移植，有的僅是個別寫作者的印象。其中哪些具有統計意義上的區分力，哪些是觀察者偏差的產物，哪些方向甚至是相反的，缺乏可對照的證據。

本研究的目標不是提出新的判別清單，而是對既有清單逐項檢驗，並給出可復算的判定程式。

## 2 方法

### 2.1 研究設計

採用對照設計。以文本來源（模型生成 / 人類寫作）為自變項，以各候選句法特徵的出現頻率為依變項。

有效對照要求控制三類混淆因素。

**主題與文體。** 生成側的話題範圍與文體設定與人類側對齊。若兩側寫作對象不屬同類，觀測到的差異無法歸因於文本來源，可能僅反映文體差異。

**模型個體差異。** 生成側採用五個模型各 60 篇，而非單一模型。研究初期曾以兩個模型的 30 篇樣本進行測算，所得結論後續大部分未能重複。以破折號為例，初期數據支援「該特徵為 Claude 獨有」，擴充至五個模型後發現另一模型的頻率更高。單一模型的個體傾向易被誤讀為生成文本的共性。

**生成條件。** 生成側不聯網檢索，不施加任何寫作風格指令，僅提供話題。附加風格約束將掩蓋模型的預設傾向。

### 2.2 語料

| 側 | 篇 | 漢字 | 句 | 段 |
|---|---|---|---|---|
| 生成 | 300 | 1,179,105 | 37,642 | 14,549 |
| 人類 | 329 | 1,647,867 | 57,909 | 31,172 |
| 合計 | 629 | 2,826,972 | 95,551 | 45,721 |

生成側模型為 claude-opus-4-6、deepseek-v4-pro、gemini-3.1-pro、gpt-5.6-sol、kimi-k3，覆蓋 38 個話題。

人類側為公開發表文本，按來源分組獨立統計。分組統計的作用在於檢驗組間一致性：若某特徵僅在個別組偏高，則更可能反映作者個人風格或文體慣例，而非人類寫作的共性。本研究中，單字虛詞與破折號兩項即由此被識別為不可靠指標。

### 2.3 文本切分

**分句。** 先按行切分，剔除標題行、表格行、程式碼塊、引用塊與列表項，再以 `。！？；` 為界斷句，保留長度不小於 4 字的片段。

剔除非正文行是必要步驟。研究初期未作此處理，僅以 `。！？` 斷句，導致 Markdown 表格與無句末標點的長列表被計為單句。受此影響，某一組的句長標準差被計算為均值的 27 倍，並據此得出「生成文本的句長均勻度為人類的 51 倍」這一結論。修正切分程式後重新測算，該比值為 0.87，即不存在差異。

**分段。** 以空行為界切分，剔除標題、表格、程式碼塊、引用、列表項與圖片行，保留長度不小於 8 字的段落。

### 2.4 分母選擇

依據被測特徵所依附的語言單位選擇分母。

| 分母 | 適用特徵 | 示例 |
|---|---|---|
| 每千漢字 | 詞彙層、標點層 | 破折號、頓號、對舉結構 |
| 每百段 | 段落層結構 | 相鄰句同構、比喻起段 |
| 同類元素佔比 | 依附於特定結構者 | 問句小標題佔全部小標題之比 |

分母選擇不當可導致方向性錯誤。生成側平均每篇含小標題約 10 個，人類側為 1 至 2 個。以每千漢字為分母時，問句小標題的比值為 32 倍；改以小標題總數為分母後，生成側 2.7%，人類側最高組 3.6%，差異消失。前一分母實際測量的是「生成文本小標題數量更多」，後者才是「生成文本傾向以問句充當小標題」。

段首類特徵的分母為非首段總數，因首段不存在可回指的上文。

### 2.5 判定標準

以頻率比 *R* = 生成側頻率 ÷ 人類側頻率作為主要判據。

| *R* | 判定 |
|---|---|
| ≥ 2.0 | 納入 |
| 1.25 ≤ *R* < 2.0 | 條件納入，需組間一致且絕對量充足 |
| 0.8 ≤ *R* < 1.25 | 無區分力，排除 |
| < 0.8 | 人類側更高，反向亦不可作為刪改依據 |

另設三項附加條件。

**組間一致性。** 人類側各組數值全距不超過 5 倍。破折號一項組間全距達百倍（最低 0.01，最高 1.29），故雖 *R* = 3.0 仍附加限定說明。

**量測規則可定位性。** 特徵須能落實到具體句段與詞形。諸如「比喻是否貼切」「並列案例是否屬堆砌」等依賴語義理解的判斷，無法轉寫為可執行量測規則，一律排除，不因主觀上「接近 AI 文風」而破例。

**改寫可操作性。** 特徵成立不等於可用於改寫。材料密度一項人類側為生成側的 2.8 倍，方向明確，但據此「補充數據」將違反資訊守恆約束，故僅保留其可執行部分，即原文已含具體數據時不得以概括表述覆蓋。單字虛詞同理，生成側確實偏低，但「補充虛詞」無法驗收，整項棄用。

### 2.6 量測規則實作

各特徵以正規表示式實現，定義置於腳本首部，可直接修改與複核。

此環節為本研究方法鏈中最薄弱者。regex 比對字面形態而不解析語義，量測規則過寬將納入大量不屬於該特徵的實例。本研究因此產生六次測量失誤，詳見第 5 節。由此確立的操作規程為：任何量測規則在採信其頻率結果前，須先抽樣檢視 20 條命中實例。

## 3 結果

### 3.1 未通過檢驗的特徵

*R* < 1.25，即不具區分力或方向相反者，共 15 項。

| 候選特徵 | 測量結果 | *R* |
|---|---|---|
| 句長均勻度 | 變異係數 生成 0.58 / 人類 0.67 | 0.87 |
| 相鄰句長差 | 生成 21.7 / 人類 21.7 | 1.00 |
| 段長均勻度 | 穩健離散度 生成 0.94 / 人類 1.00 | 0.94 |
| 單字虛詞「就」 | 生成 2.93 / 人類 6.45 | 0.45 |
| 口語連線詞 | 生成 1.01 / 人類 3.87 | 0.26 |
| 名詞復現（少用代詞） | 相鄰句同名詞起句 生成 0.02 / 人類 0.04 | 0.50 |
| 抽象被動式 | 生成 0.09 | 低於閾值 |
| 設問自答 | 生成 0.13 / 人類 0.13 | 1.03 |
| 問句小標題 | 佔小標題比 生成 2.7% / 人類最高組 3.6% | 0.75 |
| 正文設問 | 生成 0.10 / 人類 1.83 | **0.05** |
| 句內同構排比 | 同字起首兩項 生成 2.35 / 人類 3.87 | 0.61 |
| 比喻標記 | 生成 0.16 / 人類 0.38 | 0.42 |
| 抽象主語配具體謂語 | 生成 0.001 / 人類 0.001 | 0.70 |
| 動詞名詞化 | 生成 0.003 / 人類 0.005 | 0.52 |
| 正文序數詞 | 句首「首先，」生成 0.06 / 人類 0.03 | 2.00，絕對量過低 |

三項結果與流行認知方向相反，值得單獨說明。

**比喻。** 「生成文本傾向以比喻包裝抽象概念」這一判斷不成立。人類側比喻標記頻率為生成側的 2.4 倍，以比喻獨立起段者為 8 倍。差異不在是否使用比喻，而在喻體選擇：生成側偏好理想化的職業人格作喻體（「像一位智慧的導師」「一個永不疲倦的初級審查員」，*R* = 7.3），人類側多取具體個人（「像一個老師傅」「像一個人脈很廣的醫生朋友」）。前者承擔抒情功能，後者承擔說明功能。

**設問。** 正文中的設問句，人類側頻率為生成側的 17 倍。依「刪除設問」這一流行建議改寫，將使文本進一步偏離人類寫作特徵。

**句長均勻度。** 該項在本研究初期亦被認定成立，並曾報告 51 倍的比值。經查為切分程式缺陷所致（見 2.3）。修正後 *R* = 0.87。

### 3.2 通過檢驗的特徵

| 編號 | 特徵 | 測量結果 | *R* |
|---|---|---|---|
| 1 | 對舉結構（不是 A 而是 B） | 生成 0.73 / 人類 0.22 | 3.4 |
| 2 | 頓號並列過密 | 生成 3.21 / 人類 1.78 | 1.8 |
| 3 | 相鄰句結構同構 | 每百段 生成 9.41 / 人類 4.81 | 2.0 |
| 4 | 破折號 | 生成 2.38 / 人類 0.80 | 3.0 |
| 5 | 冒號濫用 | 提示語 生成 0.29 / 人類 0.08；空轉句引列表 0.29 / 0.03 | 3.8 / 9.4 |
| 6 | 序數詞充當小標題 | 生成 0.19 / 人類 0.06 | 3.1 |
| 7 | 擬人化喻體 | 生成 0.018 / 人類 0.002 | 7.3 |
| 8 | 概括表述覆蓋已有資料 | 數字密度 生成 6.34 / 人類 17.92 | 0.35（反向） |
| 9 | 起首語（說白了） | 生成 0.025 / 人類 0.008 | 3.2 |
| 10 | 譯文句式（5 種） | 見 3.4 | 2.6–5.3 |
| 11 | 段首零回指評論 | 佔非首段 生成 0.61% / 人類 0.14% | **4.4** |

通過檢驗的特徵集中於篇章與結構層面，而非詞彙或標點層面。區分力最強的第 11 項即屬篇章銜接問題：生成文本在新段落起首處直接給出評價（「聽起來像一條功能描述」「值得注意的是」），未標示評價對象，讀者須回溯上文方能確定所指。值得注意的是，段首銜接詞的總體密度兩側無差異（生成 14.4%，人類 15.1%），差異僅在於評價句省略回指成分。補入一個指示代詞即可恢復銜接。

### 3.3 模型間差異

| 特徵 | Claude | DeepSeek | Gemini | GPT | Kimi |
|---|---|---|---|---|---|
| 破折號 | 4.25 | **5.16** | 0.51 | 0.11 | 2.32 |
| 提示性冒號 | 0.38 | **0.43** | 0.22 | 0.25 | 0.32 |
| 對舉結構 | 0.61 | 0.86 | 0.29 | **1.26** | 0.51 |
| 序數詞小標題 | **1.00** | 0.69 | 0.22 | 0.73 | 0.82 |
| 過長前置定語 | 0.64 | **0.65** | 0.48 | 0.06 | 0.22 |
| 問句小標題 | 0.043 | 0.086 | **0.173** | 0.008 | 0.000 |

同一特徵在模型間的全距可達四十倍（破折號：DeepSeek 5.16，GPT 0.11）。這一結果有兩重含義。其一，不存在統一的「AI 文風」，模型個體差異不可忽略。其二，基於單一模型樣本得出的特徵描述不具普適性，本研究初期的多項誤判即源於此。

GPT 破折號頻率之低，曾被用於論證該特徵已失效。但 Claude 一項為人類側的五倍以上，而該模型在寫作場景中使用廣泛，故本研究仍予保留。

### 3.4 譯文句式的篩選

初始清單依「英文句法直接移植」設定 18 項，通過檢驗者 5 項。

| 納入 | 生成側頻率 | 排除 | 生成側頻率 |
|---|---|---|---|
| 過長前置定語 | 0.42 | 抽象被動（被認為） | 0.09 |
| 「當…時」從句 | 0.26 | 在…的過程中 | 0.07 |
| 前置話題殼（對於…來說） | 0.22 | 不僅僅是 | 0.05 |
| 句首連線詞（然而，） | 0.18 | 存在著 / 有著 | 0.04 |
| 「這意味著」複述句 | 0.15 | 進行了…的分析 | 0.03 |
| | | 使得…能夠 | 0.03 |
| | | 扮演…角色 | 0.02 |
| | | 在某種程度上 | 0.02 |
| | | 值得注意的是 | 0.02 |
| | | 以一種…的方式 | 0.01 |
| | | 一系列的 | 0.00 |

排除項中有三項為本研究規則集初始版本所自帶（「以一種…的方式」「使得…能夠」「扮演…角色」），實測頻率均低於 0.03。這些結構確屬譯文句式，但不構成生成文本的區別性特徵，現代漢語書面語已充分吸納此類句法。

## 4 從統計結果到改寫規則

統計顯著不等於可執行。本研究將 11 項通過檢驗的特徵轉寫為改寫規則時，附加了三重約束。

**白名單原則。** 僅處理清單內的 11 項。未命中任何規則的句子逐字保留，標題層級、段落次序、列表、表格與程式碼塊位置不作變動。

**資訊守恆。** 不得新增姓名、數字、日期、引語、來源、因果關係或原文未載的任何細節；同時不得刪除原文的觀點、結論與限定成分。將「可能提升」改為「提升」屬於篡改判斷強度，不屬於風格清理。判定方法為，改寫後每個實詞須能在原文中指出出處。

**語義判斷的排除。** 比喻是否貼切、設問是否解決了讀者的真實疑問、並列案例是否屬堆砌，此三類判斷依賴語義理解，無法轉寫為可執行量測規則。將其寫入規則只會誘導執行者依主觀語感改寫，故一律排除。

規則全文見 [SKILL.md](./SKILL.md)。

與寫作風格蒸餾配合使用時不必單獨安裝本規則集，[writing-dna-skill](https://github.com/larashero3-dotcom/writing-dna-skill) 已內建一份，裝該倉庫即隨行。二者構成先後兩道工序，前者負責風格逼近，本規則集負責清除生成痕跡。同目錄存在蒸餾產物時優先讀取 `語言DNA.md`；兩者衝突時以蒸餾產物為準，因其記錄的是目標作者的實際寫法，不屬生成痕跡。

## 5 測量失誤記錄

本研究在量測規則設計環節共出現六次系統性失誤，全部為量測規則覆蓋範圍寬於規則定義，且均在檢視命中實例前即採信了頻率結果。

| 初測結果 | 缺陷 | 修正後 |
|---|---|---|
| 過長前置定語 3.04 | 量測規則納入普通句式 | 0.35 |
| 並列連詞 0.26 | 規則定義為「單句內兩次以上」，量測規則測單次出現 | 0.00 |
| 「的…的…的」巢狀 0.25 | 量測規則跨頓號匹配，將正常並列計為巢狀定語 | 0.06 |
| 提示性冒號 無差異 | 6431 條命中中，標題 1266、列表 1225、對話 207，均屬規則明示豁免者 | *R* = 3.8 |
| 問句小標題 32 倍 | 分母為字數，未計生成側小標題數量本身為人類側的 5–10 倍 | 無差異 |
| 比喻包裝 0.000 | 量測規則為 11 個詞項的固定表，實際比喻表達均不在表內 | *R* = 0.42（人類更高） |

公開這一記錄有兩點考慮。其一，六項中有四項若未修正將直接進入規則集，其中兩項方向相反，據以改寫將使文本更偏離人類寫作特徵。其二，此類失誤具有共同結構：量測規則與規則名稱之間存在覆蓋範圍落差，而頻率數字本身不提示這一落差。相應的操作規程已列入 2.6。

## 6 侷限

**人類側語料規模有限。** 組間差異已相當可觀（破折號全距百倍，虛詞密度差三倍），擴充語料可能改變部分結論。

**部分特徵缺少人類側對照。** 譯文句式的篩選（3.4）僅依據生成側絕對頻率與閾值，未計算比值。某結構在生成側頻率高，不排除人類側同樣高頻。

**語義層特徵無法測量。** 篇章與修辭層面的判斷（設問是否必要、比喻是否貼切、案例是否堆砌）超出regex 量測規則的能力範圍，只能退回可定位的形態特徵。這意味著若「AI 味」的主要成分位於語義層，本研究的方法在原理上無法觸及。

**話題未嚴格配對。** 生成側為同批話題集中生成，人類側文本跨越較長時間與較多話題，部分差異可能來自話題而非文本來源。

**結論具有時效性。** 模型迭代持續向人類文風收斂。GPT 的破折號頻率在不足一年內由「近乎每句一次」降至 0.11。本研究所有頻率數值應視為特定時點的觀測。

**語料不可核驗。** 語料因版權與隱私原因未予公開，故上述數值第三方無法直接複核。可複核部分為切分規程、分母選擇、判定閾值與量測規則定義，均隨腳本公開。這是本研究的實質缺陷，非免責聲明。

## 7 復算

```bash
# 句層：各特徵在兩側語料的頻率與比值
python3 scripts/compare-human-ai.py --human <目錄...> --ai <目錄...>

# 段落層：相鄰句同構、段首零回指
python3 scripts/check-structure.py --human <目錄...> --ai <目錄...>

# 生成側：譯文句式頻率
python3 scripts/check-translationese.py <目錄...>
```

三個腳本僅按目錄參數讀取 `.md` 檔案，不含語料，亦不以目錄名作為輸出標籤。量測規則定義位於各腳本首部。

替換為自有語料即可復算全部指標。若結論與本研究不一致，請優先檢查語料的話題與文體是否對齊、分母是否與被測單位匹配。
